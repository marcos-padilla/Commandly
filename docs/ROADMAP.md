# Roadmap

Status legend: ✅ done · 🔜 next · ⏳ later

1. ✅ **Project foundation** — structure, modules, docs, scripts, placeholder UI
2. 🔜 **First-run onboarding** — multi-step welcome, feature tour, preferences, and permissions (UI shell started; preference/permission steps still placeholders)
3. 🔜 **Launcher window** — dedicated quick launcher surface
4. ⏳ **Keyboard navigation** — ranking list movement, actions, shortcuts
5. ⏳ **Command registry** — real built-in commands on CommandKit
6. ⏳ **Application launching** — Infrastructure adapters for opening apps
7. ⏳ **Quick links and snippets** — user-defined shortcuts
8. ⏳ **Search providers** — apps, files, commands (cancellable)
9. ⏳ **Clipboard history** — opt-in, privacy-reviewed
10. ⏳ **Window management** — requires Accessibility, contextual prompting
11. ⏳ **BusinessMate360 integration** — product-specific commands
12. ⏳ **Extension prototype** — after ADR, likely declarative or signed native first
13. ⏳ **Distribution and updates** — signing, notarization, updater decision

Do not implement later phases under the guise of foundation work.
