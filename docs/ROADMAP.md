# Roadmap

Status legend: ✅ done · 🔜 next · ⏳ later

1. ✅ **Project foundation** — structure, modules, docs, scripts, placeholder UI
2. 🔜 **Launcher window** — dedicated quick launcher surface
3. ⏳ **Keyboard navigation** — ranking list movement, actions, shortcuts
4. ⏳ **Command registry** — real built-in commands on CommandKit
5. ⏳ **Application launching** — Infrastructure adapters for opening apps
6. ⏳ **Quick links and snippets** — user-defined shortcuts
7. ⏳ **Search providers** — apps, files, commands (cancellable)
8. ⏳ **Clipboard history** — opt-in, privacy-reviewed
9. ⏳ **Window management** — requires Accessibility, contextual prompting
10. ⏳ **BusinessMate360 integration** — product-specific commands
11. ⏳ **Extension prototype** — after ADR, likely declarative or signed native first
12. ⏳ **Distribution and updates** — signing, notarization, updater decision

Do not implement later phases under the guise of foundation work.
